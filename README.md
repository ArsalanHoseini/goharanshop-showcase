# Goharanshop: Online Store

> 🔒 **Showcase only.** The source code is private (client project at Utab Pars).

**Live:** [goharanshop.com](https://goharanshop.com)

An online store with a **new Next.js storefront** (in active development) running on top of the existing Laravel backend.

## ✨ Highlights
- Modern, fast storefront built with the Next.js App Router
- Connected to the existing Laravel store backend
- SEO-friendly pages and PWA support on the live site

## 🛠 Tech stack
Next.js · React · TypeScript · Laravel · PHP
